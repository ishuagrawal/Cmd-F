# Privacy and data flow

Every browser snapshot is treated as private. No page content is sent just by opening the extension. Pressing Enter or Send in the pill authorizes local inspection and immediately submits the query and selected sanitized page text for that search. The default This site scope also authorizes bounded anonymous exploration of public pages on this site and relevant observed linked websites. This page limits the search to the current page. There is no additional confirmation dialog, including on account pages; typing without submitting sends nothing. The legacy developer fixture playground retains its preview and explicit checkboxes.

The backend receives the question, selected sanitized passages/control names, document and snapshot identifiers, heading context, shareable URLs, observation time, and scope. Bounded candidate text and the question go to TypeSafe/Jev. Password and form values, textarea contents, contenteditable drafts, hidden form fields, cookies, browser storage, authorization headers, and scripts are excluded from extraction.

Common email, long-number, and secret patterns are filtered; affected DOM blocks are omitted rather than claiming a redacted string is verbatim. This does not guarantee removal of every identifier, address, or billing detail. Sensitive original URLs stay out of the DTO and public frontier. Private quotations are never encoded into portable URLs.

Raw backend snapshots and provider request bodies remain in process memory only while active/paused. The panel retains its bounded local snapshot until a new search, clear, or panel close; DOM references remain local for highlighting. Completion and cancellation release the raw search request. Selected result snippets and bounded event replay remain in isolated session memory for display until explicit clear, panel close, lease expiry, or the absolute 10-minute retention limit. Closing requests deletion with a keepalive fetch; lease expiry covers missed close callbacks. A server restart drops in-memory sessions.

The extension persistently stores only an optional local application client token override. The unpacked build already contains the provisioned token. Chrome session storage holds source-tab and search IDs for worker resilience. Page text, questions, and provider API keys are not placed there. Local DOM references live in the content script and are replaced on reinspection/navigation.

Public SQLite caching is independent of user queries and contains only anonymous fetched artifacts eligible under response cache policy. There is no durable private ranking cache. Routine API logging is disabled; errors are generic and source text is not logged. Fixture test artifacts and screenshots contain owned fake data only.

Close the pill to request deletion of its search and clear its highlight. The legacy fixture playground also offers **Connection settings → Revoke this search & clear its data** and **Search coverage → Clear this search**. Each pill submission authorizes its own search; no reusable per-site consent is retained. Clearing the token field returns to this machine’s compiled connection token. Stop the local backend to disconnect. Deleting `.local/public-cache.sqlite` while the backend is stopped clears the public cache.

TypeSafe provider-side handling is governed by TypeSafe’s agreement. This repository does **not** claim provider-side zero retention. Review the provider agreement before sharing real account content. Chrome Web Store distribution and its privacy disclosures are not completed by this local preview.
